Install Walkaway.

Walkaway is a Chrome extension: it has to run inside your browser, using the accounts you're already signed into. The Chrome Web Store listing is coming; until then it takes about a minute to load by hand.

  1. Download the extension (.zip)
    Unzip it — you'll get a folder.
  2. Open chrome://extensions in Chrome and turn on Developer mode (top right).
  3. Click Load unpacked and pick the unzipped folder.
  4. Click the Walkaway icon in the toolbar → Scan my subscriptions.

The first Scan asks once for permission to check which sites you're signed into — only the site names are sent, never cookies, passwords, or history. Nothing gets cancelled, ever.
